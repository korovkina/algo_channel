Паттерн: хеш-мапа

Итак, нам даны: пары городов в массиве, порядок перепутан как во внешнем массиве, так и в парах, нужно восстановить цепочку из точки А в точку B.

```json
[
  ["Самара", "Казань"],
  ["Омск", "Уфа"],
  ["Москва", "Казань"],
  ["Уфа", "Самара"]
]
```

На собеседовании сразу уточните: гарантируется ли, что маршрут один и без разрывов? Может ли прийти пустой массив? Условие этого прямо не обещает, но мы будем исходить из того, что цепочка одна. Остальное строится на том, что каждый город посещали максимум один раз.

1️⃣ Первое, что нужно заметить: не все города встречаются в парах одинаково часто. Если взять все города из всех пар, то каждый встретится ровно дважды (прилетели, вылетели), кроме двух: откуда только вылетели и куда только прилетели. Это верно, если каждый город посещали максимум один раз и цепочка одна. Эти два города — начало и конец нашей цепочки.

```
Москва ─ Казань ─ Самара ─ Уфа ─ Омск
  1        2        2       2     1
```

2️⃣ Поймем, как эти края найти. Я бы предложила использовать хеш-мапу, где ключ — город, значение — его соседи по парам. Соседей будет либо два, если город в середине цепочки, либо один, если город в начале или в конце. Хранить соседей можно в любой коллекции. Сложность построения: `O(n)` по памяти и по времени.

```
Самара → [Казань, Уфа]
Казань → [Самара, Москва]
Омск   → [Уфа]
Уфа    → [Омск, Самара]
Москва → [Казань]
```

3️⃣ Найдем любой из городов с одним соседом. Положим его началом нашей цепочки. Напомню, что в условии сказано, что восстановить цепочку можно в обе стороны, поэтому на этом этапе мы можем выбрать любой из двух городов.

```
Самара → [Казань, Уфа]       2, дальше
Казань → [Самара, Москва]    2, дальше
Омск   → [Уфа]               1, берем за старт
```

4️⃣ Далее разворачиваем цепочку. Заводим две переменные: текущий город и предыдущий (`prev`), на старте предыдущего нет. У текущего города смотрим соседей и берем того, кто не равен `prev`. Находим его в хеш-мапе по ключу (поиск за `O(1)`), сдвигаем переменные: текущий становится предыдущим, новый — текущим. Так движемся, пока не дойдем до города с одним соседом: это конец цепочки.

```
Омск   [Уфа]            → Уфа
Уфа    [Омск, Самара]   → Самара
Самара [Казань, Уфа]    → Казань
Казань [Самара, Москва] → Москва
Москва [Казань]         → конец
```

Если пара всего одна, оба города с одним соседом, и алгоритм работает без изменений.

5️⃣ Результат (принимается любой из двух):

```
Омск → Уфа → Самара → Казань → Москва
Москва → Казань → Самара → Уфа → Омск
```

Сложность: `O(n)` по памяти, `O(n)` по времени.

Эта схема встречается и в других задачах с другим сюжетом, например в LeetCode 1743 (Restore the Array From Adjacent Pairs). Узнаете паттерн — решение то же.
