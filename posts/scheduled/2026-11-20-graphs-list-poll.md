Опрос: обычный (не викторина), анонимный, можно выбрать несколько вариантов, варианты в случайном порядке. Через 3 часа после него выходит опрос про деревья. Ответ — в общем разборе (черновик posts/draft/graphs-list-tree-explanation.md).

• У каждой вершины не больше одной исходящей стрелки
• На каждую вершину указывает не больше одной стрелки
• Есть ровно одна вершина, на которую не указывает ни одна стрелка
• Есть вершина, из которой можно дойти до всех остальных
• У каждой вершины ровно одна исходящая стрелка
• На каждую вершину указывает ровно одна стрелка
• Из каждой вершины можно дойти до всех остальных

Верные: первые четыре.
Неверные:
• «ровно одна исходящая» — у хвоста исходящих стрелок нет;
• «ровно одна входящая» — на голову никто не указывает;
• «из каждой вершины до всех» — из хвоста никуда не уйти.
