Напомню условие: дан массив чисел и число `k`, нужно найти последовательность элементов с суммой ровно `k`.

Сегодня самая мягкая версия, та самая, что была в Т-Банке: элементы идут подряд, отрицательных чисел нет.

📊 Материал среднего уровня

Паттерн: скользящее окно

Ключевая идея: держим отрезок массива (окно) и двигаем его границы так, чтобы сумма внутри приближалась к `k`. Каждый элемент входит в окно один раз и выходит один раз, поэтому весь массив проходим за один проход.

Почему это вообще работает? Из-за условия про отсутствие отрицательных чисел. Оно даёт нам монотонность: добавили элемент справа — сумма выросла, выкинули слева — уменьшилась. Никак иначе. Именно поэтому мы всегда знаем, в какую сторону двигать границу, и не гадаем.

Алгоритм:

1️⃣ Ставим обе границы в начало, сумма нулевая.
2️⃣ Двигаем правую границу и прибавляем новый элемент к сумме.
3️⃣ Пока сумма больше `k`, двигаем левую границу и вычитаем элементы. Окно сжимается.
4️⃣ Если сумма стала равна `k` — нашли ответ.

```python
def find_window(nums, k):
    left = 0
    total = 0

    for right in range(len(nums)):
        total += nums[right]              # расширяем окно вправо

        while total > k and left <= right:
            total -= nums[left]           # сжимаем окно слева
            left += 1

        if total == k and left <= right:
            return (left, right)          # границы найденного отрезка

    return None
```

Пройдём по `[2, 3, 1, 2, 4, 3]` при `k = 7`:

• Набрали `2`, `3`, `1` — сумма `6`, мало
• Добавили `2` — сумма `8`, перебор, выкидываем `2` слева
• Сумма `6`, добавили `4` — стало `10`, снова перебор, выкидываем `3`
• Сумма `7`, это ответ: отрезок `[1, 2, 4]`

Сложность: `O(n)` времени, `O(1)` памяти.

В пункте 3 стоит `while`, а не `if`. Это место, на котором легко споткнуться. За один шаг правой границы может понадобиться выкинуть слева несколько элементов подряд, а `if` выкинет только один и оставит окно с неверной суммой.

Второе, что стоит проверить: условие `left <= right`. Без него при слишком большом элементе окно схлопнется, левая граница обгонит правую, и вы получите отрезок отрицательной длины.
