Паттерн: один проход по массиву (и внимательность к краям)

Интуиция подсказывает нам простое решение: пройтись по массиву, найти самую длинную последовательность нулей и посадить нашего бедолагу в середину или рядом (если последовательность четная).

Верно ли это? Верно отчасти. Основной подводный камень, на котором попадается большинство кандидатов, включая моего студента: края ряда. В отличие от середины, где с двух сторон от пустующих мест сидят люди, на краю с одной из сторон никто не сидит. Поэтому для края (что в начале, что в конце) нужна другая логика: там нашего челика логично сажать на самый край, а не в середину. Дальше чуть поколдовать с вычислением расстояний, чтобы работало для чет/нечет, и готово.

Алгоритм:

1️⃣ Идем по массиву и запоминаем позицию предыдущего зрителя.
2️⃣ Встретили зрителя впервые — всё, что слева от него, это левый краевой пролет: кандидат в ответ равен его длине.
3️⃣ Встретили следующего зрителя — внутренний пролет: кандидат `(i - prev) // 2`.
4️⃣ Дошли до конца — правый краевой пролет: кандидат `n - 1 - prev`.

Сложность: `O(n)` времени, `O(1)` памяти.

Проверим на вчерашних примерах:
• `[1,0,0,0,1]` → садимся в середину, ответ `2`
• `[1,0,1,0,0,1,0,0,1]` → а вот и первая ловушка: пролетов из двух нулей целых два, но где ни сядь — ближайший зритель на расстоянии `1`. Длинных пролетов тут просто нет
• `[1,0,1,0]` → правый край, ответ `1`

Python:

```python
def max_dist_to_closest(seats):
    n = len(seats)
    best = 0
    prev = -1  # индекс предыдущего зрителя

    for i, s in enumerate(seats):
        if s == 1:
            if prev == -1:
                best = i  # левый край: расстояние = вся длина пролета
            else:
                best = max(best, (i - prev) // 2)  # середина пролета
            prev = i

    return max(best, n - 1 - prev)  # правый край
```

```java
public int maxDistToClosest(int[] seats) {
    int n = seats.length;
    int best = 0;
    int prev = -1;  // индекс предыдущего зрителя

    for (int i = 0; i < n; i++) {
        if (seats[i] == 1) {
            if (prev == -1) {
                best = i;  // левый край: расстояние = вся длина пролета
            } else {
                best = Math.max(best, (i - prev) / 2);  // середина пролета
            }
            prev = i;
        }
    }

    return Math.max(best, n - 1 - prev);  // правый край
}
```
