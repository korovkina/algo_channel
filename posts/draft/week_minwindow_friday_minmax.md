💡 Как правильно заводить минимум и максимум (лайфхак на пятницу)

🐥 Короткий, но сэкономит вам не один отладочный час

Пятничный снек. Тема крошечная, но на ней спотыкаются постоянно — и на собесе, и в проде. Ищете вы в цикле минимум или максимум — вопрос в том, с какого значения начать.

Главное правило, которое стоит вбить в рефлекс:

Ищем минимум — стартуем с самого БОЛЬШОГО значения. Ищем максимум — с самого МАЛЕНЬКОГО.

Звучит наоборот интуиции, но логика железная. Стартовое значение — это «пока лучший результат». Если ищем минимум и начнём с маленького числа, никакое реальное значение его уже не перебьёт, и ответ будет неверным. Поэтому старт должен быть заведомо хуже любого настоящего кандидата — тогда первый же реальный элемент его вытеснит.

Три способа задать такой старт — от универсального к контекстному.

1️⃣ `float('inf')` — бесконечность. Самый чистый приём для минимума:

```python
best = float('inf')          # для минимума
for x in nums:
    best = min(best, x)
```

Для максимума — зеркально, `float('-inf')`. Плюс: работает всегда, не надо думать о границах данных. Это дефолтный выбор, когда сомневаетесь.

2️⃣ Старт с первого элемента. Если массив точно непустой — можно взять его первый элемент за начальное «лучшее», а перебирать со второго:

```python
best = nums[0]
for x in nums[1:]:
    best = min(best, x)
```

Плюс: не нужна бесконечность, и не запутаешься со знаком. Минус: сломается на пустом массиве — надо быть уверенным, что элемент есть.

3️⃣ Старт с осмысленного предела задачи. Иногда у задачи есть естественный «максимум сверху». В нашей Minimum Window Substring мы ищем самое короткое окно — и его длина не может превышать длину всей строки. Поэтому в авторском коде:

```python
min_len = len(s)
```

Любое реальное окно короче или равно всей строке, так что `len(s)` — честная стартовая «худшая» оценка для минимума длины. Красиво и без бесконечностей.

⚠️ Типичная ошибка новичка: инициализировать минимум нулём (`best = 0`). Тогда любой положительный элемент больше нуля, и минимум навсегда останется нулём. Классический баг, который тесты ловят не сразу.

——

Всё готово к финалу. В выходные собираем полное решение Minimum Window Substring: словарь частот из среды + окно из четверга + сегодняшний старт для минимума. Там же — самое хитрое: что значит «условие соблюдается» в этой задаче и зачем счётчик уходит в минус.

——

В нашей задаче `min_len` стартует со значения `len(s)` (длина всей строки). Почему не с `0`?
— С нуля удобнее считать
— Ноль — это ошибка: минимум застрянет на нуле, ведь любое окно длиннее ✅
— Без разницы, результат тот же
