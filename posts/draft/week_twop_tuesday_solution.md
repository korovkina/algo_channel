Паттерн: два указателя (с разрывом)

Ключевая идея: чтобы найти n-й элемент с конца за один проход, пускаем по списку два указателя с разрывом ровно в `n` узлов. Когда быстрый дойдет до конца, медленный окажется прямо перед удаляемым узлом.

1️⃣ Сначала наивный способ, и он тоже неплох: два прохода. Первым считаем длину списка `L`, вторым идем до узла номер `L - n` и перешиваем ссылку. Это уже `O(n)`, и на собеседовании озвучить такой план вслух — нормальная отправная точка.

2️⃣ Но есть способ элегантнее, в один проход. Ставим оба указателя на фиктивный узел перед головой и разгоняем `fast` на `n` шагов вперед.

3️⃣ Дальше двигаем оба указателя одновременно, пока `fast` не упрется в последний узел. Разрыв в `n` узлов при этом сохраняется — значит, `slow` остановится ровно перед тем узлом, который нужно удалить.

4️⃣ Перешиваем ссылку: `slow.next = slow.next.next`. Готово.

```python
def remove_nth_from_end(head, n):
    dummy = ListNode(0, head)  # страхует случай «удалить голову»
    fast = slow = dummy

    # Разгоняем fast на n узлов вперед
    for _ in range(n):
        fast = fast.next

    # Двигаем оба, пока fast не упрется в конец
    while fast.next:
        fast = fast.next
        slow = slow.next

    # slow стоит перед удаляемым узлом
    slow.next = slow.next.next
    return dummy.next
```

Обратите внимание на фиктивный узел `dummy`. Без него случай «удалить голову» (когда `n` равно длине списка) пришлось бы разбирать отдельной веткой. С ним все случаи обрабатываются одинаково — даже список из одного элемента: `1`, `n = 1` дает пустой список без единого лишнего `if`.

Сложность: `O(n)` времени, `O(1)` памяти.

Эта задача встретилась не только во ВКонтакте, но и в Яндексе — а «удаление элементов из списка» по моей статистике вообще любимый сюжет: три компании давали его в разных вариациях.
