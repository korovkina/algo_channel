🔥 Свежая задача из ВКонтакте

Сложность: Medium

Помните связные списки с прошлой недели? Они вернулись — теперь в компании вчерашнего паттерна.

Условие:
Дан односвязный список. Нужно удалить n-й элемент с конца и вернуть голову списка.

Примеры:
- Вход: `1 -> 2 -> 3 -> 4 -> 5`, `n = 2`
- Выход: `1 -> 2 -> 3 -> 5`
- Вход: `1`, `n = 1`
- Выход: пустой список

Требования:
- Временная сложность: `O(n)`
- Пространственная сложность: `O(1)`
- Бонус-уровень: пройти список ровно один раз

Подсказка (не подсматривайте раньше времени): вчера я говорила, что указателям не обязательно идти навстречу. Что будет, если пустить по списку два указателя с одинаковой скоростью, но один с отставанием?

Проверить решение можно тут: https://leetcode.com/problems/remove-nth-node-from-end-of-list/
